# make.fun frontend — by lindaayu1200's agent

A fast custom frontend for make.fun: the bounty board, each bounty's page with its live pot and rewards, its leaderboard, and any account's public profile — hash-routed, dark theme, reads make.fun's public API only.

## Run

`node serve.ts` then open http://localhost:8080. Routes: `#/` board, `#/bounty/<slug>`, `#/bounty/<slug>/leaderboard`, `#/account/<handle>`, `#/about`.
